# Domknięcie

## Spójność z kierunkiem

| Element | Z czego wynika |
|---|---|
| Ciemna okładka: domena + figura | „dwa stany pracy”: kokpit otwiera dokument; figura to liczba najwyższej wagi, bo decyduje o kolejności pracy |
| Rozkład wag pod okładką | „jeden sygnał”: jedna linia pokazuje proporcje, zanim wejdziesz w rejestr |
| Ślad pokrycia (4 stacje) | produkt mierzy pipeline; liczby to realny wolumen, nie dekoracja |
| Rejestr bez kart, 3 px brzeg wagi | „dokładny”: czyta się jak log pomiarów, nie lista issue |
| Limonkowy kwadrat przed nagłówkiem | signature: zawsze ta sama rynna, ten sam rozmiar |
| Papier po ciemnej okładce | raport jest dokumentem do czytania i druku, nie kolejnym dashboardem |
| Waga jako słowo + kolor + pozycja | kolor nigdy nie niesie znaczenia sam |
| Copy oschłe, bez wykrzykników | charakter: nocny, dokładny, bez marketingu |

## Świadome decyzje

- **Druk / PDF** jest akcją w raporcie, bo dokument ma drugie życie poza ekranem. W wydruku okładka
  staje się jasna, a tabela zachowuje nagłówki i nie dzieli wiersza.
- **Brak kart w raporcie.** Ramką jest papier i hairline; panele byłyby językiem dashboardu.
- **Brak wykresu kołowego.** Rozkład wag to jedna linia — mniej, a czyta się szybciej.
- **Brak ikon przy wagach.** Słowo i pozycja wystarczają; kolor tylko wzmacnia.
- **Landing pokazuje prawdziwy raport w iframe**, nie zrzut. Ramka jest chrome'em podglądu, nie
  podpisem pod obrazkiem.
- **Aplikacja ma jeden akcent.** Limonka oznacza akcję i aktywny stan; statusy mają własne kolory.
- **Ruch jest ograniczony** do zmiany trasy, wejścia hero, jednego przebiegu konsoli i impulsów mapy.
  Wszystko zatrzymuje się pod `prefers-reduced-motion`.
